# Mitochondrial proteins and inflammatory phenotypes in acute respiratory failure

Analysis code associated with:

**Plasma mitochondrial-associated proteins overlap with the hyperinflammatory phenotype in acute respiratory failure**

This repository contains:
- the R code used for statistical analyses and figures;
- the Mplus code used for latent class analysis.

The analyses are based on publicly available proteomic data.
